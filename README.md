# General Baptist Heritage

Interactive historical atlas of General Baptist heritage from Amsterdam to England and beyond (1609–1891).

**[Live Demo](https://garridolecca.github.io/general-baptist-atlas/)**

## Features

- 30+ historical locations across England, Netherlands, India, and Italy
- 4 color-coded eras: Origins in Amsterdam & England, Growth & Persecution, Decline & Division, New Connexion & Revival
- 15 key figures: Smyth, Helwys, Bunyan, Grantham, Dan Taylor, Clifford, and more
- Bilingual interface (English / Spanish)
- Interactive ArcGIS map with zoom-based label collision detection
- Timeline panel, figures panel, and detailed bottom sheet navigation
- Mobile-friendly with touch gestures

## Tech Stack

- ArcGIS Maps SDK for JavaScript 5.0
- Calcite Design System
- CartoDB Positron basemap tiles
- Google Fonts (Cinzel + Inter)
- Vanilla JavaScript (ES Modules)

## Getting Started

```bash
npx serve .
```

Then open the local URL in your browser.
